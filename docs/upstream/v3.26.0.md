## Decisions

### Accepted

- Compatible Clash API, data parsing, request handling, stream lifecycle, notification, and persistence fixes.
- Proxy list virtualization, collapse motion, scroll anchoring, active-node positioning, and latency reorder behavior.
- Connection-card grouping, group expand/collapse controls, complete proxy-chain presentation, and stable virtual-table rows.
- Lazy connection GeoIP loading and cache handling.
- Controlled settings selects, floating menus, theme/background fixes, and custom CSS persistence/application.
- Compatible responsive, accessibility, table, logs, rules, and performance improvements.

### Adapted

- `App.vue`, host bridge/version behavior, proxy/connection views, settings UI, and shared styles were merged around the desktop shell rather than copied wholesale.
- sing-box continues to use the Clash-compatible API. Clash `/version` remains preferred, with the C# executable-version fallback retained for asynchronous startup and core switching.
- Existing single-active-core, Core-first navigation, embedded settings, host icon cache, and WebView lifecycle behavior were preserved.
- Upstream UI was expressed through the local `docs/style.md` token and spacing system.

### Deferred

- Reverse DNS integration that depends on an upstream DNS query endpoint.
- Additional upstream performance and browser-only test harness work that needs a separate product or test-environment decision.

### Rejected

- Upstream multi-backend management and standalone Settings workflows.
- sing-box native API, protobuf, Tools, Terminal, Tailscale, USB/IP, and OpenVPN features.
- DNS Query panels and upstream Dashboard self-upgrade controls.
- Earth Globe / projection and HonkStats cards.
- Upstream workflows that bypass the C# host for core/config upgrades.
