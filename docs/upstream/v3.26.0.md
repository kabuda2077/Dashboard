## 仍有效的取舍

- **采用**：兼容 Clash API 的数据解析、请求/流生命周期、通知与持久化修复；代理列表虚拟化、分组/滚动/测速排序；连接链路与分组、GeoIP 延迟加载；设置控件、主题、自定义 CSS、响应式与可访问性改进。
- **适配**：应用入口、桥接/版本、设置与共享样式围绕桌面宿主集成，不整文件覆盖。保留单活动核心、Core 内嵌设置、宿主图标缓存及 WebView 生命周期。
- **协议边界**：sing-box 仍走 Clash-compatible API；优先 `/version`，保留宿主可执行文件版本回退。核心/配置升级由 C# 宿主管理。
- **暂缓**：依赖上游 DNS 查询端点的反向 DNS；额外浏览器专用测试/性能工具。重新考虑时先确认产品用途和环境成本。
- **不纳入当前桌面范围**：上游多后端管理、独立 Settings、sing-box native API / protobuf、Tools、Terminal、Tailscale、USB/IP、OpenVPN、DNS Query 面板、Earth/HonkStats 及上游 UI 自升级。范围改变需要新的产品决定，不因历史拒绝永久禁止评估。
