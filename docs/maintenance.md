# 产品约束与上游跟进

本文记录 Dashboard 的产品边界、保留功能、样式与交互约束，以及上游跟进流程和项目验证入口。产品约束同样适用于自主功能开发和修复；上游登记流程仅用于跟进任务。

通用协作、实现、文档、测试及工具规则见 [AGENTS.md](../AGENTS.md)，本文不重复。基线、来源、路径和待办见 [ownership.json](upstream/ownership.json)。

<a id="desktop-shell"></a>
## 桌面壳与 Core 工作流

- 支持 mihomo / sing-box 的 Clash-compatible API，一个活动核心、两个独立 profile。页面为 Core、Proxies、Connections、Overview、Logs、Rules；设置嵌在 Core，通常折叠。浏览器预览无本机宿主权限，连接记录独立。
- 宿主管理进程、窗口、托盘、自启、文件、凭证和核心升级。核心操作统一入口、不排队；桌面选项与文件选择不暗中提交核心草稿。
- 编辑使用独立草稿，切核时明确目标；运行状态不覆盖编辑。保留脏状态、冲突和需重启提示，未改变时禁用保存；取消不改变已保存配置、运行态或背景布局/滚动，失败不显示成功。
- 首次设置可同时配置两核的 exe/config/API/Secret、文件选择与帮助；启动只提交所选草稿，API 就绪且设置保存确认后关闭。提权/启动失败保留恢复入口。Core 内的重载/丢弃确认保持原生模态、取消与焦点保护；异步设置加载后再定位，目标变化取消旧导航。
- 保留状态、Switch/Start/Stop、重载/重启、DNS/Fake IP 清理、支持的 GEO 更新、核心升级和可选 Smart 操作。版本与升级状态以宿主为准。窗口控件始终可用，普通控件不触发窗口拖动/缩放。
- TUN 栈仅在 API 已确认能力时可写，桌面 sing-box 只读。改栈保留当前开关，写后读取实际状态；界面说明可能中断连接，不把运行配置修改当作 profile 保存。
- 关闭到托盘、挂起、释放 WebView、退出分别处理；轻量模式隐藏 60 秒后释放，提前打开取消释放。提权前完成保存与退出确认，失败/取消保留旧宿主。可信桥和 DPAPI 不构成宿主与 WebView 间的强权限隔离。
- 自启任务变更前核对用户、exe 和工作目录，归属不明或不匹配时拒绝覆盖；退出等待已接受的变更及结果保存。
- 生产 UI 来源为 `http://127.0.0.1:33291/`，占用明确报错。更改来源需验证 API/WS 与安全策略，不关闭浏览器安全限制。

## 桌面视觉与已接受的选择

保持紧凑、对齐、可读及可用焦点/缩放。下表为默认字号下的 CSS px 参考；经消费者比较可等效替换，不锁死物理像素。六项已确认决定保留 ID，进一步变化需说明取舍。

桌面适应性按可用空间、实际输入方式、宿主能力和用户选择分别判断，不把窄窗口当作移动设备。保留布局重排、紧凑导航、表格/卡片选择、滚动、浮层定位和图表密度适配；底部 dock、抽屉、触摸、滑动及动画均可用于桌面，不冻结具体形态或断点。自动布局不覆盖用户选择，不隐藏窗口控件、键盘入口或必要操作；兼顾长译文、字体/缩放及低高度空间。

| 区域／决定 | 保留结果与参考 |
| --- | --- |
| Core 操作/状态 | Switch、Start、Stop 始终可见，不可用时禁用；按钮 72×34、间距 8，状态框高 36。灯 12×12、光晕 4、状态色 30%；相对 profile 卡左缘灯体 +2、状态框 +30，间隔 16；换行仍垂直居中。 |
| `core-density` | profile/options 分卡；紧凑行约 45（含分隔线），profile 到 options 标题间距 16。 |
| `core-breakpoint` | 按内容宽度低于 1000 堆叠；展开侧栏的 1120 窗口可为单列。 |
| `field-space` | 输入高 32；自然标签列上限 7.5rem，兼顾中英文、长路径和动作按钮，不裁切、不加测量循环。Save 靠 Secret，无常驻底栏。 |
| `runtime-text` | 简化运行文字；PID 按 560 内容宽度阈值呈现，完整信息留在 tooltip/可访问标签，检查与失败可辨。 |
| `dialog-density` | 设置/目标编辑对话框宽 768，受窄窗口约束；保留独立草稿与原生模态。 |
| `secret-reveal` | 默认遮掩，输入内有可访问显隐按钮；离开字段/切 profile 复位，不持久化。无法解密时先明确替换。 |
| 工具栏/侧栏 | 通用选择器和圆按钮高 36；选择器有边框、间距、选中指示和 8 圆角。侧栏展开 16rem、折叠 4.5rem，320ms 过渡中内容与工具栏对齐。受控下拉保留可定制外观。 |
| 日志 | 完整卡片内的只读滚动区，追加不撑大页面，文字可换行，加载/空/错可辨。 |

沿用 DaisyUI 语义：base-200 页面/侧栏、base-100 表面、base-200/70 次级表面、base-content 文字，/60 次级、/40 元数据；primary/success/warning 表达动作，base-border 弱分隔、base-content/20 控件轮廓。复用容器，不给每个虚拟行套卡片。桌面例外留在消费者或最后导入的 `dashboard-desktop.css`；优先 Grid/Flex/sticky，避免大范围 `!important` 和重复布局测量。

<a id="shared-controls"></a>
## 共享控件

菜单保留键盘焦点、选择、外部点击/Escape 关闭；手势不抢占横表、编辑或纵向滚动。Tooltip 兼顾触摸并安全显示文本。修改控件、样式或依赖时检查真实消费者；登记的 watch 只是线索，不是完整依赖图。确认行为和外观等价后复用上游，删除重复适配。

<a id="host-session"></a>
## 会话与数据生命周期

- 宿主拥有身份、会话代次、进程和操作结果。重启/切换即使端点相同也使旧请求失效；旧结果不得回写，命令与响应配对，增量状态可清除旧值。进程存在、API 就绪、保存完成分别呈现。
- **所有页面离开销毁、返回重建，包括概览。** 会话就绪后统一启动配置、规则、代理和连接/统计/日志流；共享任务与数据跨导航存活，不因切页重复启动，不恢复整页 KeepAlive。
- 加载、失败、未知、禁用和只读可区分，未知 TUN/API 不当作关闭，只读说明来源。清空数据不抹掉当前鉴权/连接错误；会话未就绪重探宿主，普通读取失败重试 API，写失败恢复已确认值。
- sing-box 版本优先 API、宿主版本回退。核心升级由宿主管理，运行中升级需确认新 API 就绪，失败恢复原文件并尝试重启；无摘要升级需明确确认，并绑定当前配置和运行上下文。

<a id="preferences"></a>
## 配置、凭证与持久化

- 使用 v2 配置、桥接和独立 WebView 数据目录，宿主与前端整包更新。无配置时创建完整默认值；已有格式错误保留原件并报错，不静默修补/覆盖。字段校验以 [AppSettings.cs](../src/AppSettings.cs)、[SettingsStore.cs](../src/SettingsStore.cs) 为准。
- 不迁移或删除 1.x 数据、凭证和启动项。Secret 使用当前用户 DPAPI；无法解密时使用前要求显式替换，普通保存保留原密文。
- 启动先恢复偏好，再初始化相关模块。保留原子提交、保存确认与独立草稿；挂起/释放前等待偏好、历史和图片处理完成，退出保存未确认须反馈。
- 同版本重启、窗口重建和资源替换保留浏览器数据；应用版本变化或标记无效时，仅重建 v2 WebView 数据并在成功后记录版本，失败不启动或标记完成。旧缓存策略切换重置一次，不迁回旧数据。
- WebView 重建清空浏览器连接历史/本地背景，保留宿主设置、核心、配置、图标缓存、日志及 1.x 数据；已提交偏好按启动协议恢复。

<a id="notifications"></a>
## 通知与信任边界

API、宿主和外部错误及 tooltip 按文本显示，富内容单独清洗。保留当前失败反馈、抑制旧会话错误；区分取消/失败/成功，复制或保存真正成功后才提示。浏览器后端探测区分鉴权、HTTP、超时及网络失败；网络失败可追加不带凭证的有界探测，提供离线、CORS 或混合内容线索，保留无法区分的情形。表单或会话变化取消诊断，过期结果不提示或保存。

<a id="proxy-experience"></a>
## 代理体验

保留有效文件夹、分组/筛选、标签、测速与排序、滚动恢复、dialer 名称和宿主图标缓存。虚拟化和渲染可替换，但选择、定位与导航语义须等价。代理卡片展开及遮罩按桌面消费者验证，包括关闭、焦点、滚动和窗口变化后的定位；不引入手机状态栏同步。

<a id="tables-history"></a>
## 连接、日志与规则

- 保留 Clash 字段、链路、分组、数值排序、复制、GeoIP 延迟加载和历史持久化，复用共享表格。
- 连接使用全部/活跃两个入口；重复选择全部可在菜单中切换全部/仅已关闭，并记住选择，标签说明当前视图。菜单支持键盘选择、Escape 与焦点返回。批量关闭仅处理可见且仍活跃的目标；空结果、仅已关闭、暂停及恢复后新快照到达前不发批量断开。
- 默认只搜索展示字段，可选搜索隐藏列；隐藏连接正则检查全部支持字段。列原地变化也应更新搜索结果。保留独立表头宽度/样式和正确浮层层叠，避免重复原生 title。
- 规则命中/未命中分别数值排序，有效命中时间可见，无效/缺失时间不伪造；tooltip 安全显示静态文本。忙碌/失败保持确认值，命中数不定时轮询。
- 日志有界采集，暂停/隐藏只冻结显示；恢复发布最新记录，清空包含待显示记录。WebView 释放不保证继续采集，不充当宿主日志服务。
- 连接历史正确提取可注册域名（含私有后缀）并保留 IP；来源标签匹配兼容 IPv6 zone，原始地址/正则及会话缓存语义保留。可选反向 DNS 默认关闭，手动标签优先，经当前核心查询 PTR；不支持时回退原 IP。查询有超时、并发和缓存上限，旧会话及关闭后的结果不回写；正结果按后端端点隔离持久缓存，不保存 Secret。日志 ANSI 显示和搜索能力保留。

<a id="overview-charts"></a>
## 概览与图表

侧栏速度使用 kB/s；图表默认一图，保留已有二/三图偏好、标题和图例。共享统计、IP 查询和连通性任务跨导航继续，返回显示当前结果/忙碌状态，不重复查询；网络测试四个目标、每个十次采样。隐藏、脱离文档或暂停时不绘图，局部暂停状态可随页面重建复位；暂停按钮有可访问名称与状态。保持有界数据和采样归属。

<a id="excluded-product-scope"></a>
## 排除与未采用范围

独立 Settings、多后端桌面管理、dae、sing-box native API/protobuf、Tools、Terminal、Tailscale、USB/IP、OpenVPN、DNS Query 页面、Earth/HonkStats 和上游 UI 自升级不在当前范围。改变范围需新的产品决定，相关通用修复可单独采用。代理页 Chrome 行为/性能脚本仅作为按需桌面检查，使用隔离模拟后端与浏览器数据，不加入日常 Check/Release；入口见[验证与产物](#verification)。上游部署样例、文档和测试脚本不随桌面分发。

Dashboard 面向 Windows 桌面：移动平台专属内容删除且后续不再引入，包括 iOS 状态栏/Safari 专用适配、Android/KernelSU 入口、手机浏览器安装及系统手势联动。不维护手机或移动浏览器验收。共享文件中的专属逻辑单独清理；不因 `Mobile` 命名或移动端来源删除桌面有用的布局、输入兼容或通用修复。桌面无影响的简单兼容样式可随共享实现保留，不构成移动支持承诺。清理以实际消费者为准，验证桌面能力仍然可用。

<a id="local-tooling"></a>
## 上游跟进

Dashboard 产品版本与上游版本分别管理；上游发布说明和图标工具不替换本地发布/图标链。基线及持续待办以登记为准，不在本文重复版本流水。旧 TUN 睡眠唤醒自动重启已撤下，替代方案需另行验证。

<a id="upstream-following"></a>
### 工作顺序

收到跟进请求先读本节。**默认只跟进最新正式 Release**（排除 draft/prerelease），核对发布、tag 和准确 SHA；未发布 main 不进入范围，除非用户明确指定。固定上游基线 U0、目标 U1 和本地起点（HEAD、dirty/untracked 源码），新发版留待下一轮。先核对祖先关系，已有提前采用的提交不自动回退；目标已被基线包含时保留现有基线，补齐内容按准确来源登记。

| 步骤 | 要求 |
| --- | --- |
| 分析 | 只读比较上游与本地，按功能分组，复用已有决定。向用户展示下面三类清单，不能只写在本地报告。 |
| 确认 | 留出审阅机会，必要取舍明确后实施；普通修复不逐项再问。用户明确允许直接项先做时，可推进独立部分。 |
| 实施 | 按确认范围推进，普通技术适配自行处理；说明实际改动、偏离和阻塞。 |
| 复核 | 按通用复核规则，对照确认清单检查实现和保留约束。 |
| 报告 | 对应原清单说明实际采用、决定落实、偏离、验证及限制、待办变化和交付状态。普通项简述，重要取舍展开。 |

实施前清单：

- **直接跟进**：简述问题、本地变化及验证。
- **需要确定**：说明当前/上游行为、影响、收益与代价、建议和选项；视觉变化按需提供同条件比较。新增操作、限制既有操作、持久化/权限或不确定体验变化都在此列。
- **等价实现／既定决定**：给出等价依据或规则引用，条件未变不重复询问。

**未回答不等于同意，未决不能自行改成暂缓。** 暂缓要有明确决定、原因和重审条件；已有排除/暂缓直接复用。对话决定是确认依据，工具状态不是批准证书。

### 范围与待办

功能可跨文件，文件可含多项功能；处理冲突才需说明范围例外。起点/目标固定，处理决定可修订并记录原因；补路径、消费者或归属不重建计划。替换说明新实现、旧实现退出方式和保留适配。

上游移动平台专属变化按既定排除直接跳过，不再作为待批准或待移动验收项；混合改动拆出桌面适用部分。桌面适应性、通用输入交互及其外观改进默认允许采用，照常先展示清单再实施，不仅因有移动风格而重复询问。验证鼠标/键盘入口、焦点、取消、滚动及现有状态语义，手势不抢占输入/拖动/表格操作；涉及其他产品边界、持久化或权限的新取舍仍按前述流程讨论。

旧待办自动承接，仅在本轮触及、依赖/决定改变、达到重审条件或用户要求时展开；文件交集只是线索。只审触及范围，不重审整个大组，不因同文件的小修消掉另一项未实施功能。未触发项只统计。

承接/来源闭环由工具夹具验证，日常不再模拟下一轮。

### 工具操作

使用 [review-upstream.ps1](../tools/review-upstream.ps1) 和一份可编辑 `decisions.json`：

| 操作 | 内容 |
| --- | --- |
| `-Phase Plan`（默认） | 指定干净 U0 检出 `-UpstreamRoot`、固定 `-TargetRef` 和 `-OutputDirectory`；保存起点清单并检查目标归属。人工重审用 `-Revisit <id>`。 |
| `-Phase Review`（可选） | 刷新当前清单和修订摘要，不是批准门禁，可在实施中使用。 |
| `-Phase Prepare` | 实施与必要复核收齐后，核对实际 diff/来源，更新候选登记并保存快照；指定 `-AdvanceBaseline` 才推进基线。随后运行一次既有最终检查或 Release。 |
| `-Phase Complete` | 在记录中集中填写 `review` 和 `evidence` 后，一次输出绑定候选的完成结果，不修改源码。 |

各次使用同一输出目录，后续可省上游路径；工具不 fetch/切 checkout。批次记录 ID、路径、处理方式与理由，`localPaths` 无额外消费者时可省略；未决用 `pending`，可补影响/选项/建议，暂缓用 `defer` 并写重审条件。修订填 `revisionReason`。当前格式为 schema 4，旧报告留作历史，新轮用新目录。

候选登记必须在最终验证前准备好。源码/决定变化重新 Prepare 并清除旧验证记录，输入不变则保留；完成记录不可变。原样采用、适配、替换、保留和暂缓分别记录，局部采用可保留 U0，推进基线须承接未解决项。

本地所有声明仅用于上游不存在的精确路径/专属空间，共享文件即使重写或删除也不改归属；目标新文件碰撞须审查。实际修改有明确范围，保留旧文件有有效来源，镜像哈希来自上游 blob。不得以强制选边、改指纹或迁移文件掩盖冲突。

<a id="verification"></a>
## 验证与产物

本节说明项目特有的验证条件和入口，通用测试与复核原则按 AGENTS 执行。

- 文档/工具用 `check.ps1 -Scope Maintenance`，应用默认 `-Scope Application`，两者用 `-Scope All`。正式候选直接用 `create-release.ps1 -IncludeWebViewIntegration -IncludeRealCoreIntegration`，先准备隔离核心，不先重复完整 Check。
- UI/会话修改检查真实消费者、WebView 布局/鼠标/桥接和生命周期。闲置释放先检查生产 60 秒，再加速测试计时器。复用增量类型检查与现有流水线；前端 wire 测试读取 `.tmp/reports/bridge-fixtures-v2/`，须先由本次宿主测试生成，不用旧 fixture 替代。
- 视觉比较保持 fixture、字体、主题、语言、viewport 一致，按风险选择受影响页面和窄宽/明暗/中英/侧栏状态，集中验收；不为截图或测量本身新增自动化用例。可设 `DASHBOARD_UI_VISUAL_COMPARISON=1`，结束清除；不因实现改变而删断言或直接更新参考。
- Chrome 代理行为脚本用于受影响的过滤、测速和虚拟滚动，折叠脚本用于受影响的动画、取消和卸载；首次引入或修改脚本本身时验证相应入口，不因普通跟进全跑。性能和 `OnlineUpgradeIntegration` 按影响单独选择。性能同环境/负载并确认恢复可用；宿主测量不等于应用内存或物理帧率，`alreadyLatest` 不证明实际升级。
- Release 记录 HEAD 和 tracked/untracked 输入清单，验证及发布 ZIP 前再比对，变化即停止并保留旧包。派生 app/tray.ico 不参与源快照，包内容仍逐项验哈希；Version、InformationalVersion、正式 tag 一致。

| 路径 | 用途 |
| --- | --- |
| `.tmp/tests/<run>/<case>/` | 隔离测试数据，核心夹具放 `fixtures/`。 |
| `.tmp/experiments/`、`.tmp/reports/` | 调查副本；日志、截图、wire 与测量证据。 |
| `artifacts/releases/`、`artifacts/verification/<包名>/` | ZIP；输入清单与验证摘要。历史包放 `artifacts/archive/`。 |

最终验证使用本次构建及工具自建隔离数据。pnpm 使用用户缓存，版本由 `.node-version` 和 `packageManager` 固定，安装使用冻结 lockfile，不改全局 Node、不建项目工具链缓存。项目仅编译 `src/**/*.cs`，显式排除临时/依赖目录，不能只靠 `.gitignore`。

### 开发入口

需要 PowerShell 7、.NET 9 SDK 和 pnpm 启动器，前端版本以 `.node-version` 和 `dashboard-src/package.json` 为准。现有入口负责准备依赖和构建前端。

```powershell
# 应用检查；文档/工具检查增加 -Scope Maintenance，两者用 -Scope All
pwsh -NoProfile -File .\tools\check.ps1

# 准备隔离测试核心；正式候选一次完成检查、编译和打包
pwsh -NoProfile -File .\tests\scripts\PrepareValidationCores.ps1
$env:DASHBOARD_TEST_CORES_DIR = (Resolve-Path .tmp/tests/fixtures/validation-cores).Path
pwsh -NoProfile -File .\tools\create-release.ps1 -IncludeWebViewIntegration -IncludeRealCoreIntegration
```

需要 WebView／核心集成检查时，`check.ps1` 也支持上述开关；性能测量按需增加 `-IncludePerformanceIntegration`。输出路径见本节目录表。

代理页 Chrome 脚本在 `dashboard-src/` 下按需运行，先用上述入口构建当前前端：

```powershell
pnpm test:proxy:verify
pnpm test:proxy:collapse
pnpm test:proxy:bench --groups 150 --nodes 60 --cpu 10
```

需要本机 Chrome/Chromium，找不到时设置 `CHROME_BIN` 为可执行文件路径；默认无界面，使用工具自建的模拟后端、构建快照和临时浏览器数据。性能只作同机同负载比较，不代表核心转发性能或物理显示器帧率。

## 系统验证边界

已知缺口查登记 `knownGaps`，按本轮改动选择现场检查，不每轮全量重跑：

| 涉及改动 | 现场检查 |
| --- | --- |
| 启动/提权/自启/凭证 | UAC 同意/取消、登录任务、跨账户 DPAPI、缺 Runtime/损坏包、单实例与提权接力。 |
| 窗口/输入 | DPI、跨显示器、触摸、原生焦点。 |
| 持久化/发布 | 完全退出并覆盖 EXE 后启动，宿主数据保留、版本重建、同版本资源替换、不触碰 1.x。 |
| 升级/网络/剪贴板 | 实际新版替换及失败恢复、目标网络、系统剪贴板成功路径。 |
| 睡眠恢复 | 专用 TUN/物理网络睡眠唤醒及期间切核/重启。 |

系统任务、UAC、TUN、电源和用户数据检查使用授权的专用账户/VM与隔离数据，不接管用户实例。
